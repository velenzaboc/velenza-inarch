# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please report vulnerabilities privately through either of the following channels:

1. **GitHub Private Vulnerability Reporting (Preferred)**:
   Submit a private security advisory directly at:
   <https://github.com/velenzaboc/velenza-inarch/security/advisories/new>
2. **Email**:
   Send a detailed report to **open-source@velenzaboc.com** with `velenza-inarch Security Vulnerability` in the subject line.

### What to Include

* Type of issue (e.g., authentication/authorization bypass, injection, cryptographic verification flaw, path traversal, denial of service)
* Full paths of the source file(s) related to the manifestation of the issue
* Step-by-step instructions or a minimal proof-of-concept to reproduce the issue
* Potential impact and any suggested remediation

### Response Timeline & Coordinated Disclosure

* **Acknowledgment**: Within 48 hours of receipt.
* **Triage & Assessment**: Within 5 business days.
* **Fix & Advisory**: Once a fix is validated and released, we will publish a coordinated GitHub Security Advisory crediting the reporter (unless anonymity is requested).
